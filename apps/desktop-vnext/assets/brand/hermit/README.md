# Hermit Brand Assets

这是一组基于用户确认的 Hermit Chamber 图形整理的品牌资产。主 Mark 和低饱和绿色 App Icon treatment 已接入桌面打包链路；浅色版本保留作平台视觉回归参考。

- `hermit-mark.svg`：使用 `currentColor` 的透明背景主 Mark。
- `hermit-mark-mono.svg` / `hermit-mark-inverse.svg`：黑色和白色主 Mark。
- `hermit-tray*.svg`：Tray 的 normal、paused、attention 候选。
- `hermit-app-icon.svg`：正式打包使用的低饱和绿色 App Icon treatment。
- `hermit-app-icon-light.svg`：浅色背景 App Icon treatment 参考。

通用的 Folder、Clipboard、Search、Bell、Copy、Delete 等界面图标继续使用已验证的 DSH public icons。正式发布前仍需做 16px/24px 真实宿主检查，以及 macOS/Windows 原生图标导出和资格验证。
